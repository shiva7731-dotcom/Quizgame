# 🎯 Quiz Game

An interactive and responsive Quiz Game developed using **HTML**, **CSS**, and **JavaScript**. The game allows users to test their knowledge through multiple-choice questions while providing instant feedback and a final score.

---

## 🚀 Features

- 📝 Multiple-choice quiz questions
- ⚡ Instant answer validation
- 📊 Real-time score tracking
- 🔄 Restart quiz functionality
- 📱 Responsive design for desktop and mobile
- 🎨 Clean and user-friendly interface

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/quiz-game.git
```

2. Open the project folder.

3. Run `index.html` in your browser.

No additional installation or dependencies are required.

---

## 🎮 How to Play

1. Start the quiz.
2. Read each question carefully.
3. Select the correct answer.
4. Continue until all questions are completed.
5. View your final score.
6. Restart the game to play again.
